# Python Course Notes

A collection of notes, examples, and exercises for learning the Python programming language. This repository serves as a personal reference and tracking of progress through a Python course.

## 📚 Covered Topics

This repository contains scripts that demonstrate the following fundamental Python concepts:

- **Variables**: Basics of storing data in Python (`variable.py`).
- **Typecasting**: Converting between different data types (`typecasting.py`).
- **Input**: Handling user input (`input.py`).
- **Arithmetic Operators**: Basic mathematical operations (`Arithmetic-Operators.py`).
- **Logical Operators**: Using `and`, `or`, and `not` (`Logical-Operator.py`).
- **Conditional Expressions**: Evaluating truth values (`Conditional-Experession.py`).
- **If-Statements**: Implementing control flow logic (`if-statement.py`).
- **While Loops**: Repeating code while a condition is true (`while-loop.py`).
- **Format Specifiers**: Formatting output and alignment (`Format_Specifiers.py`).
- **Math Functions**: Utilizing Python's built-in math library (`math functions.py`).

## 🚀 How to Run

To run any of the scripts, ensure you have Python installed on your system. You can run them using the command line:

```bash
python <filename>.py
```

Example:
```bash
python variable.py
```
